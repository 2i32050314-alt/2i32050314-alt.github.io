📊 CSV ↔ JSON

Excel 复制出来的表格，直接变 JSON










为什么 Excel 复制出来的表格总要清洗


从 Excel 或 WPS 复制出来的内容通常是制表符分隔；从网页表格复制是制表符；从系统导出的 CSV 可能是逗号，还可能带 BOM（\uFEFF），导致第一个字段名前面多一个看不见的字符，用 row["name"] 取不到值。工具会自动去掉 BOM，并自动判断分隔符是逗号还是制表符。


解析规则


按 RFC 4180 的简化实现：字段用双引号包住时可以包含逗号、换行；字段内的双引号用两个双引号表示（""）。这也是 Excel 导出的格式，所以带逗号的地址栏不会错位。


转成 CSV 时


JSON 数组里的对象键取并集作为表头，缺失的字段留空。字段里含逗号、引号或换行时会自动加引号包裹，保证能再次被 Excel 正确打开。


提醒


纯数字的手机号、身份证号、订单号，在 Excel 里会被截断成科学计数法。导出成 CSV 前给这类字段加前缀单引号，或者直接把 CSV 当文本处理。
