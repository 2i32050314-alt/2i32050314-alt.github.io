这个站是怎么来的

做开发和写东西的时候，一天要在十几个「在线工具」站之间来回跳：有的弹广告弹到看不见输入框，有的把粘贴的 JSON 传去服务器再返回，有的连 HTTPS 都没有。于是把最常用的十几个功能重写了一遍，全部用浏览器原生 API 实现，代码不到一个打包文件那么大，断网也能用。

它不会有会员、不会有「解锁高级功能」，也不收集你粘贴的任何内容——技术上就做不到，因为所有计算都发生在你的浏览器里。

能保证什么，不能保证什么

  • 能保证：不上传文件、不记录输入、不要求登录；工具结果与主流实现一致（哈希用 WebCrypto，颜色转换按 sRGB 公式）。
  • 不能保证：不能替代专业工具。比如图片压缩对超大图会受浏览器内存限制，正则高亮超过 500 处会截断显示。
  • 会持续改：哪个工具用着别扭，页脚有联系方式，说一声就加。
