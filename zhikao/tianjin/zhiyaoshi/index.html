天津市 执业药师 报考条件

准入类-专业技术人员 ｜ 主管单位：国家药品监督管理局、人力资源社会保障部 ｜ 公告发布：2026-07-31
本站为非官方信息整理站点，只整理官方公告中的公开字段并提供原文链接，不提供报名、培训、代报服务。 报考条件以官方公告为准。

一、是否可报（学历 / 专业 / 工作年限 / 属地 / 社保）

学历药学类、中药学类专业大专学历；大学本科学历或学士学位；第二学士学位、研究生班毕业或硕士学位；博士学位（报考条件详见公告附件1，依据国药监人〔2019〕12号、药监执函〔2019〕67号）
专业药学类、中药学类专业；药学类、中药学类相关专业相应学历或学位者，在药学或中药学岗位工作的年限相应增加1年
工作年限大专满4年；本科满2年；第二学士学位／研究生班毕业／硕士满1年；博士无年限要求。免试：取得药学或医学专业高级职称并在药学岗位工作，可免试药学专业知识（一）（二）；取得中药学或中医学专业高级职称并在中药学岗位工作，可免试中药学专业知识（一）（二）；高级职称应于报考截止日前取得
属地【待核】
社保公告未涉及社保要求（报名条件与材料条款中均无社保表述）

二、需要带的材料（清单）

#材料谁盖章 / 出具数量格式
1 学历（学位）证书及学信网在线验证/认证报告 中国高等教育学生信息网（学信网） 【待核】 PDF格式在线验证/认证报告，报名期间上传
2 符合免试部分科目条件的相关材料 【待核】 【待核】 电子版上传（免试人员）
3 《考试报名表》、身份证原件 【待核】 【待核】 现场审核（2026年8月19日）时携带

三、时间节点（报名 / 审核 / 缴费 / 准考证）

报名2026年8月7日9:00至8月17日15:00，登录全国专业技术人员资格考试报名服务平台（http://zg.cpta.com.cn/examfront）报名
审核上传材料审核自2026年8月10日9:00开始；上传材料审核未通过者于2026年8月19日（上午9:00至11:00，下午14:00至16:00）到天津市人才考评中心进行资格审核，审核由天津市药品监督管理局负责
缴费2026年8月7日9:00至8月21日15:00登录报名服务平台缴费，逾期无法补缴
准考证2026年10月28日9:00至11月1日24:00登录报名服务平台下载打印准考证

四、最容易卡住的环节

  • 上传材料审核未通过的报考人员，需携带上传电子版材料的原件、身份证原件、《考试报名表》等材料到天津市人才考评中心进行资格审核，线下审核所需材料详见审核驳回意见
  • 承诺后经核查不符合报名条件的，考试报名无效，已缴费用不予退还；已取得成绩的当次全部科目成绩无效
