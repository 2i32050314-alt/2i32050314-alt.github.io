🎨 颜色格式转换

HEX / RGB / HSL 互转，顺带算文字可读性

示例文字









三套表示法各自解决什么


    

  • HEX：最省字符，写 CSS 最常用，但看不出明暗。
    • 

  • RGB：跟屏幕像素直接对应，做透明度叠加、图像处理时直观。
    • 

  • HSL：色相 + 饱和度 + 亮度。想「让这个蓝再深一点」，改 HSL 的 L 就行；用 HEX 得重新猜十六进制。
    • 



顺手算的对比度


工具会给出这个底色上白字和黑字的对比度，并按 WCAG 标准标注：正文需要 4.5:1 以上（AA），大字（18pt 以上或 14pt 粗体）需要 3:1，AAA 要求 7:1。这不是形式主义——对比度不足的可读性问题在户外和老年用户身上非常明显。


注意色域


HSL 转 RGB 用的是 sRGB 公式，和浏览器渲染一致。如果你在做印刷设计，需要的是 CMYK，色域完全不同，不要用这里的值直接交付给印厂。


一个实用技巧


取色器支持从屏幕上拾取颜色（部分浏览器支持 EyeDropper API，Chrome 已支持）。做设计还原时比截图后用吸管工具更准。


为什么浏览器里看着一样的颜色，代码里数值不同？
可能是色彩配置文件（Display P3 与 sRGB）差异，也可能是半透明叠加的结果。
HSL 的亮度 50% 就是「正常亮度」吗？
不是。HSL 的 L 是到黑白的中点在数学上的位置，不是感知亮度。人眼对绿色更敏感，同样 L 值绿色看起来更亮。
能转 CMYK 吗？
不能准确转换——CMYK 依赖具体印刷设备和纸张，需要 ICC 配置文件，网页工具给不出可信结果。
