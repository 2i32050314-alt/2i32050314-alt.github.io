为什么不做「一键全自动」

因为这些操作本来就不该联网。你的 JSON、账单表格、身份证扫描件、未公开的稿子——传上别人的服务器，就是别人的风险。这里全部用浏览器原生 API 算，关掉网络照样能跑。
