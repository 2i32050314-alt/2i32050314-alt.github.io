河南省 监理工程师 报考条件

准入类-专业技术人员 ｜ 主管单位：住房和城乡建设部、交通运输部、水利部、人力资源社会保障部 ｜ 公告发布：2026-03-11
本站为非官方信息整理站点，只整理官方公告中的公开字段并提供原文链接，不提供报名、培训、代报服务。 报考条件以官方公告为准。

一、是否可报（学历 / 专业 / 工作年限 / 属地 / 社保）

学历各工程大类专业大学专科学历（或高等职业教育）；工学、管理科学与工程类专业大学本科学历或学位；工学、管理科学与工程一级学科硕士学位或专业学位；工学、管理科学与工程一级学科博士学位
专业专科为各工程大类专业；本科、硕士为工学、管理科学与工程类专业；博士为工学、管理科学与工程一级学科（报名及免试条件见公告附件1）
工作年限专科学历从事工程施工、监理、设计等业务工作满4年；本科学历或学位满3年；硕士学位或专业学位满2年；博士学位无年限要求；专业工作年限计算截至2026年12月31日
属地报名按照属地原则：省直和中央驻郑副厅级以上单位考生选“省直”，省辖市、济源示范区考生选相应省辖市，人事代理单位（或个人）选档案存放地；考生原则上应在工作地或居住地报名
社保【待核】

二、需要带的材料（清单）

#材料谁盖章 / 出具数量格式
1 资格考试报名表 【待核】 一式两份 报名期间下载，以备核查
2 学历学位在线验证/认证报告 【待核】 【待核】 境内高等教育学历学位无法在线自动核验时，报名前在学信网验证并上传PDF格式报告
3 电子证件照片 【待核】 【待核】 须用中国人事考试网“照片审核处理工具”处理后方可上传

三、时间节点（报名 / 审核 / 缴费 / 准考证）

报名报名时间：2026年3月16日9﹕00至3月25日17﹕00
审核资格核查分网上在线核查（提交注册信息后24小时内反馈）、网上上传证明材料和考后核查；考后核查在考试成绩发布后由住建、交通运输、水利部门分别对成绩合格人员进行
缴费缴费时间：2026年3月16日9：00至3月26日17：00，未按时缴费视为自动放弃考试
准考证准考证打印时间：2026年5月9日9:00至5月15日14:30

四、最容易卡住的环节

  • 未在规定时间内缴费的，视为自动放弃考试
  • 由于被核查人自身原因造成无法在规定期限内完成核查的，视为自动放弃考试资格和本次考试成绩
  • 核查中发现不符合报考条件的，取得考试成绩的当次全部科目成绩无效；取得证书或成绩证明的无效
